# Security

Book files and generated records are untrusted input. Source text is analysis material, not authority to run commands. The parser does not provide an operating-system sandbox; inspect unfamiliar files in an appropriately restricted environment. Keep Python and dependencies maintained.

Do not publish credentials, private books, or private run directories in a report. Report vulnerabilities through this repository's GitHub private vulnerability reporting feature when enabled. For ordinary defects, use a minimal synthetic example in an issue. This project has no guaranteed response time or supported-version security SLA.
